# NFT Alert Bot 🖼️🔔

Discord-бот, который присылает **алерты о продажах и листингах NFT** для
коллекций, которые вы сами выбираете. Подписываетесь на коллекцию в нужном
канале — и когда там кто-то покупает или выставляет NFT, бот пишет об этом
в канал.

Источник данных — [OpenSea API v2](https://docs.opensea.io/) (Ethereum,
Polygon, Base, Arbitrum, Optimism и др.).

---

## Что умеет

- Отслеживать любое число коллекций, **у каждого канала — свой список**.
- Алерты о **продажах** (`sale`), **листингах** (`listing`) или обо всём сразу.
- Фильтр по **минимальной цене**.
- Красивые эмбеды: картинка NFT, цена, покупатель/продавец, ссылки на
  OpenSea и на транзакцию в блокчейн-обозревателе.
- Управление через **slash-команды** — без правки конфигов.

## Команды

| Команда | Что делает |
|---|---|
| `/nft_watch collection:<slug>` | Начать отслеживать коллекцию в текущем канале. Опции: `event_type` (продажи/листинги/всё) и `min_price`. |
| `/nft_unwatch collection:<slug>` | Прекратить отслеживание в этом канале. |
| `/nft_list` | Показать коллекции, отслеживаемые в этом канале. |
| `/nft_test collection:<slug>` | Прислать пример последнего события (проверка). |
| `/nft_help` | Справка. |

**Где взять `slug`?** Это часть ссылки на коллекцию OpenSea:
`opensea.io/collection/`**`<slug>`**. Например, для Bored Ape Yacht Club
slug — `boredapeyachtclub`.

## Установка

### 1. Зависимости

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Токены

Скопируйте пример конфига и заполните его:

```bash
cp .env.example .env
```

- **`DISCORD_TOKEN`** — токен бота.
  1. Зайдите на <https://discord.com/developers/applications> → **New Application**.
  2. Вкладка **Bot** → **Reset Token** → скопируйте токен.
  3. В разделе **Installation** / **OAuth2** дайте боту scope `bot` и
     `applications.commands`, права **Send Messages** и **Embed Links**,
     и добавьте бота на свой сервер по сгенерированной ссылке.
- **`OPENSEA_API_KEY`** — бесплатный ключ:
  <https://docs.opensea.io/reference/api-keys> (запрос ключа на сайте OpenSea).

### 3. Запуск

```bash
python run.py
```

При старте бот зарегистрирует slash-команды (может занять до минуты, пока
Discord их разошлёт). После этого в любом канале, куда добавлен бот,
наберите `/nft_watch` и укажите коллекцию.

## Как это работает

- Бот **опрашивает** OpenSea каждые `POLL_INTERVAL_SECONDS` секунд (по
  умолчанию 60) и запрашивает новые события по каждой отслеживаемой коллекции.
- Для каждой коллекции хранится «курсор» — время последнего обработанного
  события, чтобы не слать дубликаты. При добавлении коллекции курсор ставится
  на текущий момент, поэтому историей канал не заливается — приходят только
  новые события.
- Подписки и курсоры хранятся в JSON-файле (`DATA_FILE`, по умолчанию
  `data/subscriptions.json`), так что после перезапуска всё сохраняется.

## Настройки (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DISCORD_TOKEN` | — | **Обязательно.** Токен Discord-бота. |
| `OPENSEA_API_KEY` | — | **Обязательно.** API-ключ OpenSea. |
| `POLL_INTERVAL_SECONDS` | `60` | Частота опроса OpenSea (минимум 15). |
| `DATA_FILE` | `data/subscriptions.json` | Файл хранения подписок. |
| `LOG_LEVEL` | `INFO` | Уровень логов: DEBUG/INFO/WARNING/ERROR. |

## Структура проекта

```
bot/
  config.py       — чтение .env
  storage.py      — хранение подписок и курсоров (JSON)
  opensea.py      — клиент OpenSea API v2
  formatting.py   — сборка Discord-эмбедов
  main.py         — бот, slash-команды, фоновый опрос
run.py            — точка входа
```

## Примечания / ограничения

- Данные берутся с OpenSea, поэтому отслеживаются продажи/листинги,
  прошедшие через OpenSea. Сделки на других маркетплейсах могут не попадать.
- Опрос (polling), а не вебсокет: алерт приходит с задержкой до одного
  интервала опроса. Для near-realtime можно уменьшить `POLL_INTERVAL_SECONDS`
  (осторожно с лимитами API).
- Бесплатный ключ OpenSea имеет лимиты по частоте запросов — при большом числе
  коллекций увеличьте интервал опроса.
